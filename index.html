VibeRTS / development preview

A strategy game starts with a solid foundation.

Scaffold only · Not yet playable

VibeRTS is an early browser real-time strategy project. This page confirms that the application loads; it is not a game menu or a playable demo.

What exists today

TypeScript models and draft faction, commander, damage, and veterancy reference data.

Loading reference data…

Reference data describes design ideas, not implemented game behavior. It still needs an original-content and licensing review.

What still needs to be built

  • A battlefield renderer, camera, selection, and player commands.
  • A simulation with movement, pathfinding, collision, and combat.
  • Resource gathering, construction, production, AI, and victory rules.
  • Validated save/load, progress storage, and migrations.
  • Original or properly licensed art, audio, maps, and branding.
  • A multiplayer protocol, authoritative server, and hosting.

The next playable milestone

One small map, two opposing sides, one resource, a builder, infantry, and a tank. Select units, move around obstacles, build a base, fight, win or lose, then save and resume the match.

See the repository README for local checks and deployment instructions, and docs/DEVELOPMENT.md for the development roadmap.
